# INTO Guard · your spending gatekeeper

帮你把不该花的钱,真的省下来。扫一遍你的收据邮件,揪出**忘记的订阅**、**悄悄涨价**的服务,以及**即将转扣费的免费试用**,再一步步教你怎么退。

> 当前为**纯前端 Demo**(假数据 + 浏览器本地存储),用于验证产品形态与体验,尚未接后端。全英文界面。

## 在线试用

👉 **[打开在线 Demo](#)** _(GitHub Pages 链接部署后填入)_

不需要安装、不需要登录,打开即用。你的操作只保存在你自己浏览器里,不会上传服务器。

## 怎么本地打开

直接双击 `index.html`,在浏览器里打开即可(离线也能用)。改动代码后,`Cmd + Shift + R`(Mac)强制刷新。

## 核心流程(30 秒体验)

1. **Connect inbox** — 一键(模拟)接入邮箱
2. **AI 扫描** — 12 个订阅被逐一从收据里翻出来
3. **发现漏钱** — 首页红卡:3 个忘记的订阅每年在漏 $431;琥珀卡:2 个免费试用即将扣费
4. **退订** — 点进任意订阅 → 真实可操作的退订指南 → "I cancelled it"
5. **看到省下的钱** — 首页 "Saved so far" 计数器累加

## 三个 Tab + 一个路演页

- **Home** — 每月自动划走多少 · 漏钱/试用预警 · Cancelable / Fixed 两个桶
- **Subscriptions** — 免费试用(带倒计时)· 忘记的订阅 · 活跃订阅
- **Fixed** — 房租/车贷/保险/水电等固定账单,看清 + 扣款前提醒
- **Blueprint**(顶栏按钮)— 投资人视角商业蓝图,8 段全景

## 技术说明

单文件、零依赖、零构建 —— 全部在 `index.html`(HTML + CSS + JS)。状态存 localStorage,右上角「Reset」还原演示数据。
